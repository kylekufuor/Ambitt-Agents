The editorial pages (website/editorial/*.html) also carry Satoshi, as
Fontshare's four static cuts (400, 500, 700, 900) inlined as base64 data
URIs. Each decodes byte-for-byte to the file Fontshare's own CSS API
serves for that weight (sha256 compared 2026-09-10). Base64 is a transport
encoding, not a change to the font, so the same rule holds: never
re-export, subset or optimise those cuts. Replace them only with fresh,
unmodified files from Fontshare.
