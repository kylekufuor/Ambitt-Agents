The one semantic bug this pass found and fixed. Success was #00bda5 in the portal and #00706a in the emails — both sit 3 dE from the brand teal, i.e. perceptually the same colour. An "active" pill and a brand chip were indistinguishable. Success is now a true green at 33 dE from the accent. Every status colour is now ≥33 dE from brand, so a status can never read as identity and the accent can never read as a system state.
